# petFromTeaka

Пет-проект от teaka: Telegram-бот с мемами и котиками + простая веб-страница-визитка. Без фреймворков и зависимостей — только Node.js (встроенный `fetch`, `node:test`) и vanilla JS в браузере.

## Структура проекта

| Файл / папка | Назначение |
|---|---|
| `bot.js` | Telegram-бот (основная логика, ~360 строк) |
| `bot.test.js` | Тесты на встроенном `node:test` для чистых функций бота |
| `index.html`, `style.css`, `script.js` | Статическая веб-страница «Hello, World» с IP и часами |
| `memes.json` | Кэш списка мемов с imgflip (обновляется ботом при первом запуске) |
| `cats_breeds.json` | Кэш пород кошек с TheCatAPI + русские переводы, пометки `no_image` |
| `scripts/supabase-mcp-call.js` | Мост для вызова Supabase MCP-сервера из bash |
| `supabase/` | Конфиг и SQL-миграции проекта Supabase |
| `.env` | Секреты (в `.gitignore`): `TELEGRAM_BOT_TOKEN`, `CATAPI_KEY`, `SUPABASE_URL`, `SUPABASE_ANON_KEY` |

## Telegram-бот (@petproject_teaka_bot)

### Команды

- `/start`, `/help` — справка со списком команд.
- `/meme` — случайный мем с imgflip (фото + название).
- `/cat` — случайный котик: фото породы, название (RU/EN), происхождение, характер и описание на русском.
- Любой другой текст — подсказка с командами; фото/не-текст — ответ, что бот понимает только команды.

### Требования к окружению

- Node.js ≥ 18 (используется глобальный `fetch`).
- `TELEGRAM_BOT_TOKEN` — обязателен, без него бот не стартует.
- `CATAPI_KEY` — без него `/cat` отвечает заглушкой (ключ бесплатный на thecatapi.com).
- `SUPABASE_URL`, `SUPABASE_ANON_KEY` — есть дефолтные значения в коде, можно переопределить.
- `.env` загружается собственным парсером, без зависимостей (bot.js:42-48).

### Запуск

```bash
node bot.js
```

С ярлыка на рабочем столе: двойной клик по `~/Desktop/Запустить бота.command` (открывает окно терминала; закрытие окна останавливает бота).

### Реализованные требования и особенности

1. **Long polling** через `getUpdates` (timeout 30 c); при сетевых ошибках — пауза 3 c и повтор; обработка каждого сообщения изолирована (`catch` на сообщение, бот не падает от одного плохого апдейта).
2. **Регистрация команд** через `setMyCommands` при старте.
3. **Мемы**: список берётся с `api.imgflip.com/get_memes` и кэшируется в `memes.json`; дальше работа из кэша. До 3 попыток отправки: битая картинка (не грузится по HEAD/GET или не `content-type: image/*`) — пропускаем, берём другую. Если Telegram не скачивает по ссылке — повторная отправка файлом через `multipart/form-data`.
4. **Котики**: справочник пород с TheCatAPI кэшируется в `cats_breeds.json`. Название, описание и темперамент переводятся на русский один раз (MyMemory, бесплатно, без ключа) и сохраняются в файл. Породы, у которых API не отдаёт фото, помечаются `no_image: true` и больше не выбираются. Подпись обрезается до 1000 символов, HTML-экранирование обязательно (`esc`).
5. **Без повторов**: показанные мемы/породы определяются по маркерам `[мем: id]` / `[кот: id]` в логе бота; пока не покажет всё — повторов не будет, потом пул сбрасывается. Логирование в Supabase управляется флагом `LOG_TO_DB` (сейчас `false`, тогда повторы не отслеживаются).
6. **Безопасность подписей**: экранирование `& < >` перед отправкой в Telegram с `parse_mode: "HTML"`.
7. **Обработка ошибок**: любая ошибка в обработчике → пользователю «Что-то пошло не так 😢 Попробуй ещё раз», детали — в консоль.

### Внутреннее устройство

- `tg(method, params)` — POST к Bot API, ошибки бросают исключение с телом ответа.
- `sb(path, options)` — запросы к Supabase REST с anon-ключом.
- `sendPhotoChecked()` — двухуровневая отправка фото: по URL, при неудаче — файлом.
- `translateToRu()` — нарезка текста на куски ≤400 символов по границе предложения/слова (чистая функция `splitChunks`), перевод по частям.
- Чистые функции `esc`, `parseMarker`, `splitChunks` экспортируются и покрыты тестами; запуск бота обёрнут в `require.main === module`, поэтому `require("./bot")` в тестах безопасен.

### Тесты

```bash
node --test bot.test.js
```

Покрыто: `esc` (экранирование), `parseMarker` (разбор маркеров показанного), `splitChunks` (лимит длины, сохранность текста, нарезка по предложениям, отсутствие бесконечного цикла на тексте без пробелов).

## Веб-страница (index.html)

Статическая карточка без сборки: заголовок «Hello, World!!!», кнопка переключения приветствия RU/EN, показ внешнего IP (api.ipify.org) и текущего времени, обновляемого каждую секунду. Работает с любого статического хостинга.

## Supabase

- Проект `petFromTeaka`; конфиг — `supabase/config.toml` (Postgres 17, локальные порты 54321/54322).
- Таблица `chat_messages` (`id`, `telegram_username`, `message`, `sender_type` ∈ `user|bot`, `created_at`) — лог переписки для бота; RLS включён, anon имеет insert/select. Бот пишет сюда, только если `LOG_TO_DB = true`.
- Таблицы `memes` и `meme_sends` создавались и затем удалены миграциями (`20251016000001_drop_memes.sql`) — история хранения мемов в Базе не актуальна, мемы теперь в JSON-файле.
- Миграции в `supabase/migrations/`, применяются через Supabase CLI.

## Скрипты и инструменты

- `scripts/supabase-mcp-call.js <toolName> '<jsonArgs>'` — дёргает Supabase MCP-сервер через stdio (конфиг `.kimi-code/mcp.json`, он в `.gitignore`) и печатает результат; используется как мост из bash.
- `~/Desktop/Запустить бота.command` — ярлык ручного запуска бота (не в репозитории).
